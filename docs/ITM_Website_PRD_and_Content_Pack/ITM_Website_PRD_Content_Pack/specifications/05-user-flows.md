# User Flows

## Quotation-first flow

Discover service → Review requirements → Request quotation → Consultant assessment → Clarification or document request → Quote internal review → Quote sent → Client change request, rejection or approval → Account invitation → Payment request → Payment confirmation → Application activation.

## Multi-organisation onboarding

Accept invitation → Verify identity → Create or join organisation → Confirm organisation role → Review prefilled information → Accept privacy and authority terms → Enter workspace.

## Document request

Consultant selects checklist → Client receives request → Client uploads file → Malware and format checks → Consultant accepts, rejects or requests replacement → Status and reason visible to client → Accepted document attached to requirement.

## Application progression

Awaiting documents → Documents under review → Ready to start → In progress → Submitted to authority → Authority feedback → Client action required or continued processing → Completed.

## Content review

Draft → Editorial review → Regulatory review where required → Scheduled or published → Review reminder → Reconfirmed, revised, suspended or archived.
