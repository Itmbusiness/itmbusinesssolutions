## URL rules

- Lowercase hyphenated slugs.
- Stable `/services/{slug}` URLs for services.
- Stable `/services/category/{slug}` URLs for categories.
- Articles use `/articles/{slug}`.
- Dashboard URLs are non-indexable and require authentication.
- Changed published URLs require permanent redirects and updated internal links.
