## Frequently asked questions

### Is the P4 return monthly?

NSSA’s published guidance describes the P4 as a monthly return accessed and e-filed through the employer self-service portal.

### What does the P4 contain?

It provides a breakdown of employee contributions so individual member accounts can be credited.

### Can you correct previous periods?

Outstanding periods can be assessed and quoted based on data availability and complexity.

### Can the service run automatically?

Reminders and tasks can be automated, but figures should still be reviewed and approved by authorised people before submission.
