# Requirements Centre

Use these checklists to prepare for assessment. They are starting guides, not final authority lists.

## Find a checklist

Search by service, organisation type or document name.

Each checklist displays:

- Service and applicable organisation types
- Required, conditional and optional items
- Accepted file formats
- Whether an original, certified copy or ordinary copy may be requested
- Date last reviewed
- Link to the complete service page

## Before uploading

Make sure documents are readable, complete and belong to the correct organisation. Hide unrelated personal information only when the request allows it. Never send official-portal passwords through an ordinary upload or chat.
