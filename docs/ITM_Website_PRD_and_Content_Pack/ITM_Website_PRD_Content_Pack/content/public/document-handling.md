# Preparing and Sending Documents Safely

- Upload only documents requested for the selected organisation and application.
- Check that every page is readable and correctly oriented.
- Use the secure application upload rather than general email or chat where available.
- Never send passwords, PINs or one-time codes through ordinary messages.
- Remove unrelated personal information only when the requirement allows it.
- Report an incorrect upload immediately.

Accepted formats and limits are displayed at upload time. Files are checked before consultant access and every replacement remains versioned for audit purposes.
