# Search Services and Resources

Search by outcome, service, requirement or question.

Results are grouped into Services, Requirements, Articles and General Pages. Each result displays content type, title, short description and reviewed date where applicable.

No results message: “We could not find an exact match. Describe what you need and a consultant will help identify the right service.”

## Search tips

Try describing the outcome, such as “apply for tenders,” “register employees,” “submit returns” or “open a shop,” instead of entering an authority abbreviation only.
